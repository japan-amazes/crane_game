# BGM の楽譜データの形式

`bgm.json` を差し替えると、アプリの BGM が変わります（最後まで行くと最初に戻ってくり返します）。

```json
{
  "title": "曲名",
  "bpm": 132,
  "stepsPerBeat": 4,
  "tracks": [
    { "name": "メロディ", "wave": "pulse25", "volume": 0.22, "notes": "C5:2 E5:2 G5:4 -:8 | ..." },
    { "name": "ベース",   "wave": "triangle", "volume": 0.35, "notes": "C3:2 C4:2 ..." },
    { "name": "ドラム",   "wave": "noise",    "volume": 0.18, "notes": "K:2 H:2 S:2 H:2 ..." }
  ]
}
```

- `bpm`：テンポ
- `stepsPerBeat`：1拍を何マスに分けるか（4 なら 1マス＝16分音符）
- `swing`（省略可）：跳ね具合（0＝跳ねない、0.3前後でシャッフル。0.33で3連符のノリ）
- `swingUnit`（省略可）：何マスごとに裏を遅らせるか（初期値 2＝8分音符の裏が跳ねる）
- `wave`：音色
  - `pulse25`（ファミコンのメロディらしい音）
  - `pulse12`（細く鋭い音）
  - `square`（太い音）
  - `triangle`（ベース向き）
  - `noise`（ドラム）
- `volume`：音量（0〜1。0.1〜0.35 くらいが目安）
- `gate`（省略可）：音を伸ばす割合（0〜1、初期値 0.85。小さいと歯切れよくなる）
- `notes`：`音名:マス数` をスペース区切りで並べる
  - 音名は `C4` `F#5` `Bb3` のように書く（C4＝ド、数字が大きいほど高い）
  - 休符は `-`。例：`-:4`
  - ドラムトラックは `K`（バスドラ）・`S`（スネア）・`H`（ハイハット）
  - `|` は小節の区切り（読みやすさのためだけで、無視される）
  - 各トラックのマス数の合計は揃える（いちばん長いトラックの長さでくり返す）

## GPT への依頼文（そのまま貼る用）

> クレーンゲーム練習アプリの BGM を作ってください。ファミコン風のピコピコした明るい曲で、くり返し再生してもつなぎ目が自然なループにしてください。既存の曲のメロディを使わず、完全にオリジナルにしてください。
>
> 出力は次の形式の JSON だけにしてください。
> - `bpm`（120〜150くらい）、`stepsPerBeat` は 4
> - 跳ねるノリにしたいときは `"swing": 0.3, "swingUnit": 2` を付ける
> - `tracks` は 3〜4本：メロディ（wave: "pulse25"）、ハモリまたは伴奏（"pulse12"）、ベース（"triangle"）、ドラム（"noise"）
> - 各トラックの `notes` は「音名:マス数」をスペース区切りで並べた文字列。音名は C4、F#5、Bb3 の形式。休符は "-:マス数"。ドラムは K（バスドラ）S（スネア）H（ハイハット）。小節の区切りに "|" を入れてよい
> - 1小節＝16マス。8〜16小節。全トラックのマス数の合計を必ず同じにする
> - volume の目安：メロディ 0.22、ハモリ 0.12、ベース 0.35、ドラム 0.18
>
> 例：
> `{"title":"曲名","bpm":132,"stepsPerBeat":4,"tracks":[{"name":"メロディ","wave":"pulse25","volume":0.22,"notes":"C5:2 E5:2 G5:4 -:8"}, ...]}`
